## GitHub
The GitHub repository for the Create: Terraworks modpack on Modrinth.
This repo contains the files from the .mrpack file, and can additionally be used for issue reporting.
You can find the modpack here: https://modrinth.com/modpack/create-terraworks  

NOTE: The modpack is currently under review by modrinth. You cannot download it just yet!


## Features

### Create mod and a bunch of add-ons
Add-ons featuring: Aeronautics, New Age, Copycats+, Slice & Dice, Central Kitchen, Enchantment Industry, Connected, Numismatics and wayyyy more!

### Better vanilla-like world generation
Using Terralith and Tectonic, the world is vast, while keeping it's vanilla charm!
Using Enderscape and Amplified Nether, the nether is much larger and the end got a complete vanilla-like update!

### More structures to explore
A bunch of new structures to explore, including small vanilla-like additions to whole new bosses, with vanilla structures being revamped aswell! Loot is player individual, meaning you don't have to share with friends. Your backpack will help you carry more stuff!

### Accessories
On your journey, you might find artifacts and other things you can wear outside of your usual 4 armor slots. They all have their own unique abilities!

### Chisel
There is a single item called Universal Chisel. This Chisel can transform almost any block into a bunch of variants, making building way more exciting!
There is also some simple vanilla-like Furniture, and a lot of create mod decorations!

**Note: This modpack is pretty heavy and requires a decent PC. It is recommended to allocate at least 8 GiB of RAM.**
